# S09 — Parent dashboard & weekly report

- Phase: P3 · Status: Proposed

## User story
As a parent, I want to see where my child is weak by topic and error type, and get a weekly digest, so that I can choose what to practise on the weekend.

## Behaviour
- Radar by error_category; bar chart by knowledge point; trend of MASTERED/week.
- Weekly digest page (shareable link) summarising new items, mastered items, relapses.

## Acceptance checks
- [ ] Charts render server-side as SVG (no heavy chart libs).
