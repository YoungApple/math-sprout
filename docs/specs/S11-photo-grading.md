# S11 — Photo grading of handwritten quiz answers

- Phase: P3 · Status: Proposed

## User story
As a child, I want to solve variants on paper and photograph the result, so that I can show my working instead of typing a number.

## Behaviour
- Variant card offers "拍作业"; Gemini reads the final answer and flags process errors; same grading path as typed answers.

## Acceptance checks
- [ ] Agreement with typed grading ≥ 95 % on a 50-sample set.
