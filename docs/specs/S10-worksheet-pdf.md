# S10 — Printable worksheet export

- Phase: P3 · Status: Proposed

## User story
As a parent, I want to print an A4 sheet of clean variants for weekend practice, so that screen time stays low.

## Behaviour
- Select by topic / status / date range → A4 PDF with numbered problems and an answer key page.
- Uses clean stems (S07) and freshly generated L1/L2 variants.

## Acceptance checks
- [ ] Prints correctly from iOS Safari share sheet and desktop Chrome.
